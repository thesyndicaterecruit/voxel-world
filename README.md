# Voxel Island

A tiny block world for your pocket: a 512×512 archipelago that streams in around you, with your
islands saved in the browser. Three.js + TypeScript + Vite.

**Play:** https://thesyndicaterecruit.github.io/voxel-world/ (rebuilt on every push). Add `?seed=123` for a fixed world.

```sh
npm install
npm run dev     # open the Network URL on your phone (same Wi-Fi)
npm run build
```

See [CLAUDE.md](CLAUDE.md) for the project structure, conventions and roadmap.
